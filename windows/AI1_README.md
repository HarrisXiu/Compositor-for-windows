# AI1：离线推理与模型管理

截至 2026-10-03，AI1 的 C++ 推理基础层、模型管理和完整离线自测试包已接入并通过当前范围的本地回归。主体/物体选区、边缘细化和去背景的应用交互仍待开发，不能将当前状态称为完整 AI 功能完成。Windows 预览版保持 0.4.0。

## 支持范围

| 硬件 | 当前处理方式 |
| --- | --- |
| 受支持的 Intel 核显 | 优先使用 DirectML；初始化或推理失败时回退 CPU |
| Intel 核显与 NVIDIA/AMD 显卡同时存在 | 自动选择受支持的 Intel 核显 |
| 只有 NVIDIA/AMD、Intel 独显或没有可用 Intel 核显 | 使用 CPU |
| NVIDIA CUDA | 后续单独实现，当前不可用 |

NVIDIA/AMD DirectML 已退出适配和验收范围。Intel 核显默认使用已验证的通用 DirectML 内核。诊断开关不能绕过硬件范围限制；严格 GPU 测试也不会把 CPU 回退算作 GPU 通过。

## 已完成的内容

- C++20 推理：后台运行、取消、CPU 回退原因记录、设备丢失与 NaN/Infinity 输出保护。
- 图像预处理：缩放、归一化、填充和点击坐标转换；与 Python ONNX 参考结果对比。
- SAM 编码缓存：同一图像的多次点击复用特征，支持迭代蒙版输入。
- 模型管理：菜单入口、本地导入、SHA256/大小校验、原子安装、许可缓存及离线使用。
- 下载基础设施：续传、取消、损坏文件和受控离线场景回归已完成；正式模型地址仍未发布。
- 打包：运行库、Qt 插件、第三方通知及对应许可随便携包部署。应用运行不依赖 Python。

## 完整测试包

当前交付文件位于仓库工作树下：

~~~text
artifacts/ai1/intel-only-self-test/AI1-complete-self-test.zip
~~~

包大小为 **1,657,956,111 字节，约 1.66 GB**。模型、参考张量/图片、应用、探针、8 组测试程序、运行库、Qt 插件和许可证已全部包含，263 个文件已通过 SHA256 校验。此路径仅指本地交付文件，不是公开下载地址。

在另一台 Windows 10/11 x64 电脑上：

1. 将完整 ZIP 复制到本地磁盘并全部解压。
2. 打开解压后的 **AI1-self-test** 文件夹，双击 **开始测试.cmd**。
3. 结束后带回同目录中生成的 **results-日期时间.zip**。

无需安装 Python、Qt、Visual Studio，也无需旧包、联网或管理员权限。测试会自动校验文件、记录硬件/驱动、运行基础测试和真实模型。只检查受支持的 Intel 核显 GPU；其他显卡标记为 `skipped` 并注明超出范围，没有受支持的 Intel 核显时验证 CPU 回退。结果 ZIP 不含模型权重，也不会自动上传。

默认双击即可完成测试。可选参数和结果字段见 [跨机器自测试说明](AI1_SELF_TEST.md)。旧的增量诊断包保留用于历史追踪，当前测试使用上述完整包。

## 已验证的结果

| 检查 | 当前证据 |
| --- | --- |
| Release 构建 | 成功 |
| CTest | 8 组全部通过 |
| Intel UHD 真实模型 | 150/150；四种模型、三张图，Profiler 确认 GPU 节点执行 |
| 选中 NVIDIA 时的 CPU 回退 | 132/132；编码器、解码器均在 CPU，DirectML 节点为 0 |
| Intel 无效输出与设备丢失回归 | 两次独立运行各 3/3 Qt 测试通过，无跳过 |
| PowerShell 5.1 范围选择 | 4/4：无 Intel、混合显卡、显式 NVIDIA、显式 Intel |
| 实际解压包运行 | 完整性、TLS、8 组测试、应用启动及 CPU 回退通过 |

Lite 在 Ryzen 7 7800X3D 的九次 CPU 推理平均约 **3.84 秒/图**；i9-13900HX 在 12 线程时约 **3.80 秒/图**。这些时间不含模型加载和预处理，不是跨硬件速度保证。默认 CPU 线程数为逻辑处理器的一半，限制在 1–12。

验证范围是 ONNX 数值一致性和运行库/基础功能回归；真实分割质量、头发/肖像效果和 Mac 视觉一致性仍需独立验收。历史 NVIDIA/AMD GPU 失败日志原样保留，没有改记为通过，也不再阻塞 Intel 核显范围的 DirectML 验收。
