## 使用

1. **多边形套索**：按 `L` 选择套索，在工具选项勾选「多边形」。`Tab` 切换自由 / 多边形模式。逐点点击；`Enter`、双击或点击起点闭合。`Backspace` 删除上一个点，`Esc` 取消。工具栏的替换 / 添加 / 减去 / 相交模式可用；第一点按 `Shift` 添加，`Alt` 减去，`Shift+Alt` 相交。
2. **扩展 / 收缩**：建立选区后，使用「选择 > 扩展… / 收缩…」，输入像素半径。计算中可取消；取消不改变选区或撤销栈。画布外的覆盖为零，因此贴边选区也会收缩。
3. **蒙版**：选择目标图层或文件夹，使用「选择 > 用选区建立蒙版」或「图层 > 用选区建立蒙版」。这会替换该目标原有的蒙版。图层像素保留，保存项目会保存蒙版。
4. **色彩范围**：使用「选择 > 色彩范围…」。在左侧图像上取色，右侧显示黑白蒙版，画布同步显示选区。取色为点击位置的 3×3 含透明度加权平均；取色模式为替换 / 添加 / 减去，也可按 `Shift` 添加、`Alt` 排除。调整容差和反选，等待预览完成后确认。清除取色和取消均恢复原选区；未取色或计算中不能确认。

色彩范围直接复用原版 `WandPixels.c` 的 `color_range_mask`：逐通道 sRGB 容差匹配，输出二值蒙版。普通匹配排除完全透明像素，反选会反转整幅覆盖，包括透明区域；需要柔边时可再羽化。它不进行主体识别。
