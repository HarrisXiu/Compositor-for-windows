# Windows 0.4 完善阶段报告

日期：2026-10-02。依据用户提供的《Windows与原版差距及完善方案》，本轮完成阶段 0 的本地架构、会话状态与选区历史工作，以及阶段 1 的混合循环优化。**当前仍是未完全完成的预览版，后续将持续更新。视口分块渲染和完整原版功能对齐尚未完成。**

## 本轮实际变化

1. 将约 2300 行的 `editor.cpp` 拆为主窗口、项目页/历史、菜单、图层面板、工具选项及新建/导出、滤镜、效果、文字/形状对话框。职责与扩展方式见 [ARCHITECTURE.md](ARCHITECTURE.md)。
2. 引入 `CanvasTool` 接口，各工具通过按下、移动、松开、键盘、叠加绘制和取消钩子处理事件。相关工具共享绘画/形状/选区内核，画布 QWidget 统一分发事件。
3. 每个 `EditorPage` 独立拥有选区、前景色、背景色、像素/蒙版目标、工具及参数，切换标签不再覆盖其他项目的颜色和绘画参数。新增前景/背景拾色入口，X 交换、D 复位；Esc 取消手势，空格临时平移。
4. 矩形/椭圆/套索/魔棒、全选/取消/反选及羽化进入撤销/重做。裁剪或画布改尺寸时，选区与文档一起恢复。取消手势不产生历史记录。
5. 将“已保存的内容状态”与选区历史分开：选区变化不会制造未保存标记或关闭提示。后台保存记录它实际写入的内容状态，期间继续编辑后仍显示未保存，撤销回已保存内容时恢复干净状态。保存前取消尚未提交的手势，避免保存半笔画。
6. 混合模式先解析为枚举，像素/通道循环内不再比较字符串；Normal 使用独立路径，大于等于 65536 像素的表面按行并行。工作线程使用互不重叠的原始行指针，目标图像在启动前只分离一次。
7. 保留工作区已有的 Qt 许可证和对应源码打包改进，并更新 Qt Concurrent 的实际部署说明。README 已明确注明未完成及后续持续更新；`artifacts` 保持被 Git 忽略。

项目自身 MIT 协议未变，自动更新继续排除。应用版本为 0.4.0；`.comp` 格式仍为 11，未添加保存字段。仍使用 C11/C++20，不需要 Rust 或 Python 运行时。

## 验证

本地 Release 构建、便携打包及五组测试通过。最终 XML 位于本地 `artifacts/tests-0.4-*.xml`，通过记录包含初始化/清理；不能将这些数字解释成已完成的功能数量。

| 测试组 | 通过记录 | 失败 | 跳过 |
| --- | ---: | ---: | ---: |
| Core | 93 | 0 | 1 |
| UI | 30 | 0 | 0 |
| Photoshop | 18 | 0 | 0 |
| RAW | 6 | 0 | 0 |
| Dither | 17 | 0 | 0 |

Core 中跳过的是默认关闭的耗时基准；已单独开启并运行通过。新增覆盖包含全部 24 种混合模式、不同透明度、半透明/完全透明/不透明输入、串行与并行路径及同图像源/目标别名，均与冻结的 0.3 实现逐像素一致。UI 覆盖选区撤销/重做、羽化、尺寸变化恢复、取消、标签会话隔离和真实后台保存期间编辑。

本机单次基准对 1600×1000 图像连续合成五次：Normal 原实现约 14873 ms，新实现约 68 ms；Multiply 原实现约 2237 ms，新实现约 64 ms。数据见 `artifacts/blend-benchmark-0.4.txt`。这只是混合循环基准，**不等于整个应用或大文档画笔提升同样倍数**，不同机器结果会变化。

GitHub Windows CI 通过推送触发，远端结果以 `codex/windows-cpp` 对应提交的 Actions 页面为准；本表记录本地验证结果。尚未完成全新 Windows 环境验证和 Mac 参考图对比。

## 运行与剩余范围

完整便携包：`artifacts/Compositor-Windows-x64.zip`。解压后运行 `Compositor-Windows-x64/Compositor.exe`，保留 DLL、插件和许可证文件。中/英/日语言切换仍在视图菜单。Qt 对应源码另存于本地 `artifacts/qt-source`。

阶段 1 的视口渲染、256×256 分块缓存、笔迹区域重算、mipmap、全分辨率吸管/魔棒缓存及 GPU 尚未实现；画布预览仍有 1600 像素上限，不能宣称已达到 6000×4000、20 图层连续绘画的验收目标。完整键盘表、标尺/吸附、变换手柄、多选、浮动选区、画布文字输入、非模态滤镜、恢复机制、AI 分割等仍待后续阶段。详见 [PORTING_STATUS.md](PORTING_STATUS.md)。

本轮交付并推送后，按用户要求停止开发，等待下一步指示。生成文件和用户提供的 Word 文档留在本地 `artifacts`，不提交到仓库。
