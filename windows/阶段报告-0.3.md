# Compositor Windows 0.3.0 阶段报告

报告日期：2026-10-02。当前状态：**已生成可运行的 Windows x64 Release 预览版；尚未完成与 macOS 原版的全部功能对齐。按用户要求，本阶段交付后暂停，等待审阅。**

## 交付与运行

- 完整便携包：项目根目录下 `artifacts/Compositor-Windows-x64.zip`。
- 可运行程序：`artifacts/Compositor-Windows-x64/Compositor.exe`。
- 使用方式：解压完整 ZIP，进入 `Compositor-Windows-x64` 文件夹，双击 `Compositor.exe`。请保留同目录的 DLL、插件目录及其他依赖文件；单独复制 EXE 不足以运行。
- 本版为 C11/C++20 实现，使用 Qt 6.10.2 和 LibRaw 0.22.2；不需要 Rust 或 Python 运行时。构建工具为 MSVC / CMake。
- 语言切换入口：`视图 → 语言` / `View → Language` / `表示 → 言語`。支持简体中文、English、日本語，切换即时生效，选择会保存。
- 可通过帮助菜单打开演示项目，检查图层、画布和编辑操作。
