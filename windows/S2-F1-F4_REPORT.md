# S2 / F1–F4 交付

## 范围与基线

分支 `feature/s2-f1-f4` 基于 `the-one-for-windows` 的 `15837df`，完成开发计划中的 S2（浮动选区与选区变换）和 F1–F4（实时预览框架、色阶/曲线/色相饱和度、Camera Raw 面板、越界模糊与 JPEG 导出预览）。应用仍为 0.4.0，`.comp` 格式仍为 11；新增状态都属于会话或对话框，不写入项目。

| 任务 | 本轮结果 |
| --- | --- |
| S2 移动选区轮廓 | 选框 / 套索 / 魔棒在「替换」模式下拖动选区内部只移动轮廓，Shift 锁定轴向，一次撤销「Move Selection」；Esc 取消。选区内单击：魔棒从该点重新取样，其余工具取消选择（与原版一致）。方向键 1 / 10 像素移动轮廓沿用 C1 |
| S2 移动 / 复制选区像素 | Ctrl 拖动移动选中像素，Ctrl+Alt 拖动复制，一次撤销；原地松开不产生撤销；Esc 精确还原。Ctrl+方向键改用同一机制：**像素移出图层边缘时图层扩展，不再被裁掉**（修复原缺陷） |
| S2 Ctrl+T 变换选区 | 有选区时 Ctrl+T（或「选择 > 变换选中像素」）把像素提升为浮动图层，选区作为其蒙版随之变换：移动、缩放、旋转、Ctrl 拖动自由扭曲均可，多次手势不入撤销栈；Enter 合并为一次「Transform Selection」撤销，选区随像素变换；Esc、撤销 / 重做恢复到 Ctrl+T 之前的精确状态。切换工具、菜单命令、图层面板、保存、关闭会先合并 |
| F1 实时预览框架 | 滤镜 / 调整对话框不再阻塞窗口，结果直接显示在画布上。滤镜在后台按屏幕比例的缩小副本计算（最多 1600 万像素），只保留最新请求、旧结果丢弃；调整图层交给画布渲染器。「预览」开关；对话框打开时画布只能平移缩放，面板 / 标签页锁定，其它菜单命令先取消对话框，视图菜单保持可用 |
| F1 滑块与拖动调值 | 所有数值参数为「可拖动标签 + 滑块 + 输入框」：横向拖动标签调值（Shift 精细、Ctrl 粗调），双击标签或滑块恢复默认值 |
| F2 色阶 | 原始像素按透明度和选区加权的分通道直方图（后台计算）；输入黑 / 灰 / 白与输出黑 / 白三角手柄可拖动；自动「对比度 / 颜色 / 颜色+中性中间调」；黑 / 灰 / 白场吸管在画布上取原始像素（调整图层取其下方画面） |
| F2 曲线 | 当前通道直方图衬底，选中点显示输入 / 输出，删除点、重置曲线 |
| F2 色相 / 饱和度 | 彩色滑块轨道；前后两条色谱与当前范围的四个色带手柄可拖动；「改为作用于此范围之外」；取样 / 添加到范围 / 从范围中减去吸管；目标调整：在画布上横向拖动调整该颜色饱和度，按 Ctrl 调整色相；着色从 0° / 25% 开始 |
| F3 Camera Raw | 以侧边面板停靠窗口右缘、占满高度；画布实时预览，裁切 / 锐化蒙版指示只画在预览上；悬停 RGB 读数（静止时随预览刷新）；调色四个色轮（角度 = 色相，距离 = 饱和度）；取样点颜色 / 几何参考线 / 白平衡 / 去边取样可直接在画布上操作；新增目标调整：在画布上上下拖动按该处色调移动参数曲线区段，或按该处色相调整混色器（色相 / 饱和度 / 明亮度可选） |
| F4 越界模糊 | 高斯模糊、动感模糊、辉光先按影响范围扩展图层（3σ+2、半条拖影+2、3×半径+2），模糊不再在图层边缘截断；实时预览同样扩展（只增不减）。内容识别填充在选区越出图层时扩展图层覆盖选区 |
| F4 JPEG 导出预览 | 导出 JPEG 时显示实际编码结果（适合窗口 / 100%）、文件大小、品质滑块和透明区域背景色，后台编码；写出的字节与预览完全相同，品质记忆 |

## 已知限制

- 选区仍是画布大小的灰度蒙版。~~轮廓或浮动像素移出画布的部分随之丢失~~：已在 `feature/parity-gaps` 补齐，移回时完整恢复，只有 Ctrl+T 缩放、旋转后的选区仍会丢失超出部分。拖动轮廓时不吸附参考线，原版同样不吸附。
- 浮动选区只处理像素图层，不处理图层蒙版目标；变换后合并会重采样（整像素平移除外）。
- 正在运行的预览任务无法中途打断，只丢弃其结果，原版同样如此。~~OK 后的全分辨率应用仍在界面线程同步执行~~：已改为后台执行，见 [功能缺口补齐](PARITY_GAPS_REPORT.md)。
- 噪点 / 颗粒 / 抖动在缩小预览中与最终结果的颗粒感不同；扩展后的图层保留透明边距，不自动裁回。
- Camera Raw 侧边面板为停靠在窗口右缘的工具窗口，不是可拖入布局的停靠面板；画布上绘制几何参考线时不显示临时线段（对话框缩略图上可见）。
- 未进行 Mac 参考图对照和真实设备的人工交互验收。
